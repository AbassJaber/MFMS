## Project Description:

The Municipal Financial Manangement System (MFMS) is a C-based application developed to help a municipality manage basic financial and administrative information. The system provides modules for employee management, budget management, supplier management, asset management, and reports. It allows users to enter, store, search, calculate, and display relevant municipal information through a menu-driven interface.

## System Features: 

Menu-driven main system
Employee management
Add employees
Display employees
Search for employees
Calculate employee salary information
Budget management
Enter departmental budgets
Enter expenditure
Calculate remaining budgets
Determine whether expenditure is within budget
Identify departments that have exceeded their budgets
Supplier management
Add suppliers
Display suppliers
Search for suppliers
Compare/search supplier information
Asset management
Add and manage municipal assets
Display asset information
Search for assets
Reports
Employee reports
Budget reports
Supplier reports
Asset reports
Input validation
Search functionality
Use of arrays, strings, functions, loops and decision-making

## How to Compile:

Using GCC, compile the program with:

gcc main.c employees.c budget.c supplier.c reports.c -o mfms

## How to Run: 

Run the compiled program with:

.\mfms.exe
